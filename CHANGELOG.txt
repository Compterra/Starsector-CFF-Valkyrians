# Valkyrians Changelog

This translated root changelog consolidates the legacy Chinese update notes into an English-facing summary. The detailed legacy English changelog remains available at docs/Valkyrians_Changelog.txt.

## 4.0.2

- Reworked the Fearless Tour procurement step to require one mothballed Yoshura-pattern capital instead of three rare battleships.
- Added clearer quest guidance for acceptable Yoshura hulls and likely acquisition routes.
- Removed an unused internal quest test hook from the shipped runtime class.

## 4.0.1

- Removed the old Valkyrian-only portrait set from the faction and player portrait lists.
- Switched Valkyrian generated officers to vanilla human portrait pools by default, avoiding gender-mismatched missing portrait references.

## 4.0.0

- Updated the mod for Starsector 0.98a-RC8 as a restoration release.
- Fully polished major mission briefings, codex descriptions, faction text, and player-facing labels.
- Added the Valkyrian Logistics Liaison and Orken-Enigma War Coordination Bureau structure chain with a screened procurement storefront.
- Rebalanced and clarified Brynhildr Rotary Core, Valhalla Core, and Holy Covenant behavior and tooltips.
- Fixed the Battle for Heaven's Gate and Valkyrian Database mission text issues caused by stale compiled jar classes.
- Removed unused debug and duplicate combat plugin classes from the shipped jar.
- Added GitHub-backed Version Checker support for the restoration fork.

## 3.3.11

- Polished weapon codex descriptions for the cruise missile and GR Lance families so each entry has a clearer role and lore identity.
- Replaced generic weapon role labels with more specific refit/codex roles for several fighter, beam, missile, and heavy artillery weapons.

## 3.3.10

- Audited custom weapon and hullmod text against their actual scripts and CSV stats.
- Clarified Recon System Enhancement, Skogul S-mod effects, Peak Fire charging rules, Flux Fog activation timing, Redsteel Armor S-mod effects, and Sunfury torpedo blast radius wording.

## 3.3.9

- Polished mission briefings, quest dialogue, blueprint item text, and several codex descriptions for more natural English prose while preserving the original lore beats.

## 3.3.8

- Fixed Sunfury torpedo sprite path capitalization for case-sensitive systems.

## 3.3.7

- Fixed Jenova's missing Weapon Flux/Sec stat display by giving the decorative Jenova ECM Power Loop system weapon a finite charge-down value.

## 3.3.6

- Fixed the Holy Covenant War Program hullmod tooltip in the Codex. The hullmod now shows a generic doctrine overview when no ship is attached, while preserving ship-specific details in refit/combat contexts.

## Localization and Restoration Pass

- Translated player-facing metadata, ship names, designations, manufacturers, fighter roles, weapon names, weapon tooltip roles, hullmod text, ship system names, blueprint package text, market condition text, mission briefings, mission UI labels, faction display names, channel names, and codex descriptions.
- Reframed older lore notes into a cleaner Valkyrian faction background, with Orken Manufacturing Group, Horizon Shipyards, and Enigma Company presented as major industrial blocs.
- Cleaned juvenile and translator-note style prose from public docs and mission text.
- Standardized Valkyrian ship class terminology and retained the mod's core theme: a disciplined independent military power built around advanced lasers, missiles, heavy guns, carrier groups, and rare super-capital hulls.

## Legacy Development Summary

- Valkyrians received a dedicated star system and a reworked royal armada.
- Added and revised several missions, including Chasing Memories, Kingsbane, Battle for Heaven's Gate, Past the Storm, Star Destroyer, and Unexpected Trouble.
- Rebalanced Valkyrian weapons, fighters, point defense, cruise missiles, and lancer-family weapons across prior releases.
- Added ShaderLib/GraphicsLib support, custom engine sounds, decorative lights, new hulls, new weapons, and remodeled ships over the original development cycle.
- Removed obsolete variants, unused sounds, and old internal hull concepts from active gameplay.
